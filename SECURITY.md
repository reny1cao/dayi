# Security

Dayi handles draft text, Accessibility permissions, model credentials, and local history. Do not include API keys, private drafts, URLs containing tokens, or raw history databases in an issue.

For a suspected vulnerability, use the repository's **Security → Report a vulnerability** option when enabled. If that private channel is unavailable, open a minimal issue requesting a private security contact; do not post exploit details or sensitive data there. A stable public reporting channel must be confirmed before the repository is opened.

No stable public release or support window exists yet. The preview has incomplete notarization and brand-asset review. Do not rely on it for unsupported background editing or unattended security-sensitive workflows.
