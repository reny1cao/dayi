# Dayi 默认润色模板

当前版本：`dayi-default-1`。资源位于 `Sources/PolishCore/Resources/default-polish-template.json`，通过 `PromptTemplate.bundled()` 加载。

这份模板按 Dayi 的产品要求新编写，没有沿用旧模板的正文、示例、提取元数据或引号剥离正则。旧文件及相关实现的原始副本和 SHA-256 清单已保存在仓库外的私有来源档案中。旧 Git 提交仍含退役材料；替换当前资源不等于清除旧历史，也不替代项目开源许可与其他第三方材料的审查。

## 行为范围

- 编辑草稿本身。问题仍是问题，代码请求仍是请求，不直接回答或执行草稿中的任务。
- 保留意图、语言、语气、确定程度、条件、排除项和请求的交付物。数字、标识符、路径、URL、占位符与引用文字保持准确。
- 改善措辞、语法、标点和已有信息的顺序，不凭空增加技术选型、功能、期限或验收要求。
- 清楚的输入允许少改或不改，不设置强制扩写倍数和固定字数上限。
- 只返回替换正文，不新增解释、外包引号或代码围栏。输入中有意义的引号和格式保留。

这是一个默认策略，不增加分级增强 UI、网站专用策略、附件读取或会话上下文。网站识别仍只用于来源记录；模型请求不新增网站上下文。

## 本机编辑与预览

打开「设置 → 提示词」可查看和编辑系统提示词、用户提示词；用户提示词必须且只能包含一个 `{input}`。示例输入只用于本地预览，不会调用模型。点击「保存并启用」后从下一次请求生效，运行中的请求保留原模板；「撤销未保存修改」回到当前生效内容。「恢复默认内容」先把 repo 的默认模板填回编辑器，保存后才恢复默认使用状态。

本机自定义内容保存在已有私有 SQLite 数据库，`prompt.custom-skill` 指向不可变技能版本。保存新版本、归档旧自定义版本、更新选择在同一事务完成；保存失败不切换当前配置。恢复默认清除覆盖选项，后续跟随应用自带默认版本。应用升级不覆盖用户的自定义提示词；本地打磨不自动改变 repo 内的默认资源。

## 输出与历史关联

模型输出只去掉首尾空白，不再猜测首尾引号是不是模型添加的包装；自动剥离可能破坏真实引用。HTTP 错误、空结果、未完成响应和原位写回保护继续由现有流程处理。模型偶尔不遵循格式仍属于质量问题，不能通过任意删除正文字符来掩盖。

模板版本变化时，既有启动逻辑归档旧 built-in skill 并新建当前技能。旧记录继续关联旧模板；自定义技能保持原状；再次启动不会重复新增同一版本。用户本机旧技能不会被重命名、改写或删除，也不会随 App 打包发布。

每个润色任务开始时绑定具体模板内容与 skill ID。之后用户切换提示词不会把正在运行的结果错误归到新版本。默认资源在进程启动使用时载入内存，后续请求不再逐次依赖 App 路径上的模板文件。

## 验证与维护

`swift test` 覆盖字面插入（包括 `{input}`、Unicode）、输出引号保留、生产请求内容以及旧技能到新版本的持久化关联。

`Tests/Fixtures/DefaultPrompt.json` 提供 8 条合成草稿，覆盖中文范围约束、英文数字/API、混合语言、问题、未经验证的推测、引用/URL/占位符、翻译请求和分项清单。可显式启用 `liveDefaultPromptOnSyntheticDrafts`，通过生产 Polisher 请求测试；默认测试不调用收费模型：

```sh
# 使用显式 POLISH_ENDPOINT / POLISH_MODEL / POLISH_API_KEY 环境变量，勿提交密钥。
mkdir -p work
POLISH_LIVE_DEFAULT_PROMPT=1 \
POLISH_EVAL_OUTPUT="$PWD/work/default-prompt-results.json" \
swift test --filter liveDefaultPromptOnSyntheticDrafts
```

输出只包含合成输入、模型输出、响应模型名称及关键词检查结果，不记录凭据。关键词保留只是一项检查，不足以证明原意没有变化；需要逐条复核是否新增要求、把推测写成事实、执行了请求或改变语言。单一模型的小样本通过不等于所有模型或真实客户端验收。

后续修改任一 prompt 字段时更新 sourceVersion，重新验证语义和历史关联；不让历史记录错误地指向修改后的模板。

### 2026-09-11 本轮结果

使用本机已保存的 `deepseek-flash`，由生产 Polisher 实际请求 8 条合成草稿。首轮人工复核发现混合语言中的英文短句被翻译，补充逐语言片段保留规则后重跑全部 8 条；第二轮逐条检查，问题未被回答、否定/条件/不确定性保留、引用和标识符未丢失，混合语言短句保持。英文代码标识符有一次被加上行内反引号，含义未改变；本策略不承诺输出排版与输入逐字相同。

最终模板与测试样例哈希记录在忽略目录 work 中的评测清单，原始结果同样仅含合成数据。171 项 Swift 测试运行通过（收费测试默认跳过）；App release 打包与签名验证通过，新模板与源码一致，退役模板文件与旧系统提示词正文未进入 App。独立模板替换阶段未重启现用进程；后续本机提示词设置阶段已重启新构建，并验证编辑、保存、重启恢复和恢复默认。真实客户端自定义提示词快捷键流程仍需单独验收。
