# Dayi 0.2.4 — preview 2

**Apple Silicon · Developer ID signed and notarized.** App 0.2.4, build 8.

## Changed since preview 1

- A second ⌃⌥P in an input whose text no longer matches a waiting result now polishes the current text. Before, the expired result kept claiming the key: every press retried a write that could not succeed, and no new polish could start in that input until the record was dismissed. The expired record stays in the activity window, marked as a conflict, for copying.
- Localization directories are found under both SwiftPM layouts (lowercase on Swift 6.3, source case on Swift 6.4), so a Chinese interface no longer crashes at first use on a build from a newer toolchain.
- MIT license adopted; Chinese README; demo videos.

## Download contents

- `Dayi-0.2.4-preview.2-macos-arm64.zip`: signed, notarized and stapled app.
- `release.json`: source commit, architecture, signing/notarization status.
- `notarization-log.json`: Apple's notarization log for the submitted archive.
- `SHA256SUMS.txt`: hashes for the three files above. Verify with `shasum -a 256 -c SHA256SUMS.txt`.

## Still open

Intel and minimum-macOS acceptance, a clean-machine installation check, Firefox/Edge/Brave editing flows, rich-text editors with input-method composition. Web and Electron inputs still need the original window in front to apply a result.
