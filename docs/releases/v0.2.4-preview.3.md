# Dayi 0.2.4 — preview 3

**Apple Silicon · Developer ID signed and notarized.** App 0.2.4, build 9.

## Changed since preview 2

- **Fixes a hang.** Hiding the sidebar in the activity window sent the app into an endless layout cycle at 100% CPU until it was force-quit. The inspector is now attached to the split view instead of the detail column, which ends the cycle.
- The activity table answers accessibility queries with the rows on screen only. Enumerating every record used to build more than a thousand cell views on the main thread, so any assistive client polling the window could keep the app unresponsive.
- **Automatic updates.** This is the first build that checks the project's appcast through Sparkle. Update checks fetch one static file from `https://reny1cao.github.io/dayi/appcast.xml`; system profiling is off. Sparkle asks once whether it may check automatically; **Check for Updates…** is in the menu bar panel and the app menu.
- A landing page at <https://reny1cao.github.io/dayi/> and a rewritten README first screen.

## Download contents

- `Dayi-0.2.4-preview.3-macos-arm64.zip`: signed, notarized and stapled app.
- `release.json`: source commit, architecture, signing/notarization status.
- `notarization-log.json`: Apple's notarization log for the submitted archive.
- `SHA256SUMS.txt`: hashes for the three files above. Verify with `shasum -a 256 -c SHA256SUMS.txt`.
