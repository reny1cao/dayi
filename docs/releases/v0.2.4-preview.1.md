# Dayi 0.2.4 — first preview preparation

**Private draft · Apple Silicon · not yet approved for public distribution.**

This preview adds the selected Dayi icon, website-aware activity and automatic site icons, saved/custom model profiles and model discovery, Chinese/English UI, configurable shortcuts, and native activity/layout improvements. The app retains target-bound edits, read-back checks, and conflict-aware session undo.

## Download contents

- `Dayi-0.2.4-preview.1-macos-arm64.zip`: Developer ID-signed app, version 0.2.4, build 7.
- `release.json`: source commit, architecture, signing/notarization status, and outstanding public gates.
- `SHA256SUMS.txt`: hashes for both files. Verify after download with `shasum -a 256 -c SHA256SUMS.txt`.

No stable public install is advertised. The package declares macOS 14+ but has been exercised locally on macOS 26; Intel/minimum-version acceptance remains pending.

## Before trying the preview

Use your own model provider/API key. Grant Accessibility to the installed app. Default polish shortcut is Control–Option–P; undo is Control–Option–Z. Saved shortcuts are preserved. The app never sends your draft automatically.

Web/Electron write-back currently needs the original input foreground. The new Dayi default prompt edits requests without answering them and preserves meaning, language, and constraints. Complex rich-text editors and the physical-browser hotkey-to-new-icon sequence require further acceptance. History persists locally; undo does not survive app exit.

## Public release blockers

- Project code is MIT licensed as of 2026-09-15. The retired extracted prompt has been replaced in current app resources; private source history still contains retired material, so the public repository was seeded as a fresh history from the release commit. Third-party/brand assets require review before public distribution.
- The candidate is Developer ID signed but **not notarized or stapled**. Signing is not a substitute for Apple's notarization service or a clean-machine installation check.
- The repository remains private; this draft does not authorize changing its visibility.

See the readiness report and runbook in `docs/releases/`. This draft is intentionally not a public open-source launch.
